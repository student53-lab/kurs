Примітки. Токени `cta` і `on-cta` у файлі задані посиланням на інший токен (`{orange}`, `{ink-deep}`) без окремого значення для темної теми: у темній вони беруть те саме значення, що й у світлій. Значення «Світла тема» й «Темна тема» для токенів без теми повторюють єдине значення, бо воно діє в обох темах.
