Мітка типу заняття або умов відвідування: коротке слово у формі пігулки.

Споживач надає: короткий текст (до трьох слів). Класи: `tt-tag` (зелена, тип заняття), `tt-tag--sand` (нейтральна, вік), `tt-tag--orange` (умова, наприклад «Без запису»).

- Зелену мітку вживай лише для типу заняття в розкладі (творчість, англійська, музика, логіка); текст `ink-deep`.
- Мітка не є кнопкою: не роби її клікабельною і не клади в неї єдину важливу інформацію без дублювання в тексті.
- Розмір тексту 16px, не менше. Більше трьох міток в одному рядку не став.
