Картка для ціни, заняття за розкладом або майстер-класу: заголовок, короткий опис, мітки й кнопка.

Споживач надає: заголовок (`h3`), 1–3 речення, мітки, за потреби кнопку «Записатися». Клас: `tt-card`.

- Поверхня `card` із тінню `shadow-card`, кути `radius-lg`, внутрішній відступ `space-5`; розміщуй на `bg` або `sand`.
- Між картками — `space-5`. На смартфоні картки стають в один стовпець на всю ширину, від 768px — два, від 1120px — три.
- Ціну набирай `body-strong`; у картці вільного відвідування кнопки немає, є мітка «Без запису».
- Не став у картку більше однієї кнопки; не додавай лівих кольорових смуг.
