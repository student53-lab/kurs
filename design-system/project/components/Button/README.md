Кнопка запису: головна дія сайту — переглянути послуги й записатися на заняття.

Споживач надає: текст кнопки (дієслово, наприклад «Записатися»), посилання або дію. Класи: `tt-btn` (основна), `tt-btn tt-btn--secondary` (вторинна).

Стани основної кнопки:

- Звичайний: заливка `cta`, текст `on-cta`, рамка 2px `ink-deep`, тінь `shadow-cta`.
- Під курсором: заливка `cta-hover`, кнопка вище на 2px, тінь `shadow-cta-hover`.
- У фокусі: суцільне кільце `focus` 3px з відступом 3px (з клавіатури, `:focus-visible`).
- Натиснута: заливка `cta-active`, кнопка нижче на 4px, тінь прибрано.
- Відключена: фон `sand`, текст `ink-soft`; використовуй рідко й поясни причину текстом.

Правила:

- Одна основна кнопка на екран. Вторинна `tt-btn--secondary` — для додаткової дії; на лендингу TipToe її зараз немає. Кнопки «Подзвонити» немає: телефон дано текстовим посиланням `tel:`.
- Висота не менша за 48px; текст 18px Nunito Bold, `on-cta` — ніколи не білий.
- Для вільного відвідування кнопку «Записатися» не показуй, а став мітку «Без запису».
- Закріплених кнопок немає: ні вгорі в шапці, ні внизу екрана. «Записатися» стоїть лише в самому вмісті: у рядках розкладу, картках майстер-класів і формі. У шапці лишаються тільки навігація, перемикач теми й перемикач мови.
